# xquik changelog

## [v2.0.1]

### Added

- **xquik joins the Fieldkit marketplace for Claude Code and Codex.** The
  package routes bounded Twitter/X search, profiles, trends, SDK integrations,
  exports, monitors, webhooks, and account actions through the current Xquik
  REST or MCP contract. Private, persistent, metered, media, and
  account-affecting operations require explicit confirmation.
